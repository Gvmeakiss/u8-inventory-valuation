# U8财务核算流水账版存货发出计价CAATS

本目录是从既有仓库管理流水账程序隔离复制出的独立版本，只处理：

`input/current/财务核算-流水账 记账日期-2026.01-.06.xlsx`

该文件为客户于2026-08-14重新提供的完整记账日期版本，替代本代码分支此前使用的`财务核算-流水账-2026.01-0.6.xlsx`。旧输入及旧输出继续保留，仅用于版本比较。

原项目根目录下的`src/`、`config/`、`tests/`及原`run_pipeline.sh`不作为本版本运行入口，也不会被本版本覆盖。

## 1. 字段映射与数据粒度

新流水账工作表为`流水账`，第2行为表头，每一条有效记录代表一个仓库、一个存货、一个U8收发明细。程序会排除底部`总计`行。

| 标准用途 | 财务核算流水账字段 | 处理 |
| --- | --- | --- |
| 月份 | 记账日期 | 唯一期间字段，格式化为`YYYYMM`；不使用单据日期 |
| 单据追溯 | 单据日期、单据号、凭证摘要 | 仅用于证据追溯和辅助识别单据类型 |
| 已记账 | 记账人 | 非空才纳入 |
| 仓库主键 | 仓库编码 | 匹配仓库档案，并复核仓库名称一致 |
| 成本仓 | 仓库档案.记入成本 | 仅`是`纳入 |
| 物料 | 存货编码 | 按物料+月份归集 |
| 移动方式 | 业务类型 | 排除`调拨入库`、`调拨出库` |
| 收入 | 收入数量、收入单价、收入金额 | 保留原始正负方向 |
| 发出 | 发出数量、发出单价、发出金额 | 保留原始正负方向 |

2026年1—6月新清单中，存在单据月份与记账月份不同的记录。因此，修改期间字段会改变月份归属，属于计算口径变化；本版本在代码、ITA口径说明及运行日志中均明确锁定`记账日期`。

## 2. 计算口径

1. 读取六个月收发存汇总表，过滤`存货编码=合计`。
2. 财务核算流水账仅纳入`记账人非空`且仓库档案`记入成本=是`的记录。
3. 月份只取`记账日期`。
4. CAATS剔除`调拨入库`和`调拨出库`；本清单不使用借入借出类别。
5. 以物料+月份执行月末一次加权平均模拟，并生成月度独立、连续滚算、差异明细及跨仓抵销结果。
6. U8月表原值先减去已记账成本仓流水中的调拨出入库，再与CAATS筛选后流水及重计算结果比较。
7. REVIEW仅表示差异超过0.01元，需要进一步审阅，不等同于已确认错报或调整金额。

## 5. 质量控制

完整运行会执行：

- 输入文件SHA-256清单；
- 月间期初期末衔接检查；
- 仓库编码及名称双重匹配；
- 调拨剔除明细与01、03、ITA桥接钩稽；
- 连续滚算四段式金额钩稽；
- Final月份物料覆盖检查；
- 工作簿ZIP、Sheet顺序、公式错误和关键字段检查；
- Python计算单元测试。

本版本的源字段和限制详见ITA工作簿`09_口径说明`及`10_检查`。
