# U8财务核算流水账记账日期版CAATS

更新时间：2026-08-17
适用期间：2026年1—6月

## 1. 版本定位

本目录是当前有效的独立执行版本，使用客户重新提供的财务核算流水账：

```text
input/current/财务核算-流水账 记账日期-2026.01-.06.xlsx
```

月份只取`记账日期`，不使用`单据日期`。仓库管理流水账版及旧财务核算流水账版保留用于历史比较，不作为本版重跑入口。

本程序模拟“物料+月份”的全月一次加权平均价，并提供连续滚算敏感性分析。客户实际普通成本单据更接近“仓库+物料+月份”，特殊成本单据可能按“仓库核算组+物料+月份”统一计价，因此CAATS物料维度差异用于风险识别，不等同于确认错报或建议调整金额。

## 2. 输入文件与字段

| 角色 | 默认路径 | 关键字段/用途 |
| --- | --- | --- |

| 月度收发存 | `input/current/收发存汇总/*.XLS` | 物料+月份的期初、收入、发出、结存数量及金额 |
| 仓库档案 | `input/current/仓库档案.XLS` | 仓库编码、计价方式、仓库核算组、记入成本 |
| CAATS模板 | `input/current/CAATS交付模板.xlsx` | 结果表基础样式 |

财务核算流水账每条有效记录代表一个仓库、一个物料的一笔收发明细；底部总计行不纳入。编码字段按文本处理，保留前导零。

## 3. 纳入范围与差异方向

CAATS流水同时满足：

```text
记账人非空
AND 仓库档案.记入成本 = 是
AND 业务类型不属于调拨入库、调拨出库
```

本财务核算流水账版只剔除调拨入库、调拨出库，不使用借入借出移动类别。

01及03按以下顺序保留审计轨迹：

```text
U8月表原值
- 已记账成本仓调拨出入库
= U8剔除后比较值
→ CAATS筛选/重算值
→ U8剔除后值 - CAATS值
```

金额差异统一采用有方向金额，不对财务审计展示“绝对差异”。`REVIEW`表示差异超过0.01元，需要进一步分析，不代表已确认错报。

## 4. 计算逻辑

### 4.1 月度独立重算

对每个“物料+月份”：

```text
CAATS月末平均价
=（客户U8期初金额 + CAATS计入收入金额）
 /（客户U8期初数量 + CAATS计入收入数量）

CAATS发出金额 = CAATS计入发出数量 × CAATS月末平均价
CAATS结存金额 = 客户U8期初金额 + CAATS计入收入金额 - CAATS发出金额
发出金额差异 = U8月度发出金额（剔除后）- CAATS发出金额
结存金额差异 = U8月度结存金额（剔除后）- CAATS结存金额
```

每月独立使用U8月表期初，因此上月CAATS差异不会进入下月月度独立结果。

### 4.2 连续滚算敏感性分析

每个物料第一次出现时使用当月U8期初；之后月份承接最近一次可追溯的连续CAATS期末。程序从物料首次出现月份至2026年6月建立完整月份面板，无收发月份补零收发记录并承接期初和期末，不因中间缺月重置。

```text
连续期初 = 首次出现使用U8期初；其后使用上月连续CAATS期末
连续发出金额 = CAATS计入发出数量 × 连续月末平均价
连续期末金额 = 连续期初金额 + CAATS计入收入金额 - 连续发出金额
```

完整滚转关系：

```text
期初承接结存差异
+ 本期收入金额差异
- 本期发出金额差异
- 本期期末结存差异
= 0
```

发出差异是期间流量；结存差异是时点余额。各月发出差异可以按期间求和，期末结存差异不能跨月累加，同一物料只取Final记录评价期末存货。

### 4.3 02和04余额汇总

`02_物料月维度结果汇总`逐月汇总：

- 客户U8期初数量、金额；
- CAATS结存数量、金额。

`04_连续滚算汇总`逐月汇总：

- 客户U8期初数量、金额；
- 连续CAATS期初数量、金额；
- 连续CAATS结存数量、金额。

04的`合计/Final`行只取首月客户U8/连续期初和6月Final连续结存，不把各月余额相加。

### 4.4 物料类别与存货科目

CAATS的01、03、05、06在物料类别编码及名称后直接展示存货科目编码及名称，不另设映射页，也不展示映射状态。

- 物料类别按存货编码唯一匹配，不根据名称或编码前缀猜测；物料类别缺失时，用该物料已匹配的存货科目（编码+名称）兜底填充。
- 存货科目先按仓库匹配，再按最长物料类别前缀取规则；无类别或无特定前缀时，落到该仓库的默认科目（存货分类编码为空的行）；仅当仓库无默认行时才标"类别缺失待补充"。
- 同一物料在1—6月已记账成本仓流水涉及多个存货科目时，去重后用`、`连接。
- 本期无收发流水（仅期初/结存）的物料无仓库记录，类别与科目均留空。

## 5. 输出工作簿

### 5.1 财务审计主结果

`U8存货发出计价_CAATS审计结果表.xlsx`

1. `01_物料月维度明细`
2. `02_物料月维度结果汇总`
3. `03_连续滚算明细`
4. `04_连续滚算汇总`
5. `05_月度独立差异明细（对应01）`
6. `06_连续滚算差异明细（对应03）`

### 5.2 调拨剔除支持明细

`U8存货发出计价_调拨出入库剔除明细.xlsx`

1. `01_收入剔除明细`
2. `02_发出剔除明细`
3. `03_收入金额差异明细`

收入和发出剔除明细按物料+月份汇总后，分别与01、03及ITA桥接一致。若U8剔除后收入金额与CAATS计入收入金额全量一致，03页保留“本期无差异记录”的明确说明。

### 5.3 ITA内部核对证据

`U8存货发出计价_ITA核对钩稽数据.xlsx`

包含输入清单、月间衔接、流水桥接、仓库物料月、物料月桥接、仓库组特殊单据、仓库档案、口径说明和完整性检查。ITA用于内部自核，不作为财务审计主结果表。

## 9. 结论边界和新增数据

- 连续滚算未模拟U8自动调整单、成本卷积调整和最终取价调整，仅作为敏感性分析。
- 未取得按仓库+物料列示的月初数量和金额前，仓库维度不能形成完整独立重算结论。
- 特殊单据的最终会计正确性仍需结合成本卷积结果、调整单和凭证判断。
- `REVIEW`和净差异不能直接作为账务调整金额。

新增数据时，应先冻结原文件及哈希，更新`config/project.json`期间，验证字段和编码格式，再使用新的`run_id`执行。原始业务文件只读，历史输入和历史输出不得覆盖。
